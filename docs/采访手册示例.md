# 讲述者｜人生访谈手册

采访前：说明录音用途、AI 处理方式和参与人员，取得本人或合法授权人的同意。
建议每次 20–40 分钟。一次只问一个问题，允许休息、跳过或停止。不要暗示答案。
录音时先说出日期、地点、采访者与讲述者。敏感内容和不公开内容请单独标记。
每段经历补问：大约哪年？在哪里？有哪些人？发生了什么？当时的感受是什么？
不确定的信息记为「待核实」，不要替讲述者补全。方言名词、人名、地名请另记读音与写法。
